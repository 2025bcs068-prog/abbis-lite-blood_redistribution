## Authorship

The project history so far was authored from this workstation using Biyimbwa's configured GitHub account, `2025bcs068-prog` (`2025bcs068@std.must.ac.ug`). It is not attributed to the other four members. Each teammate must make their own meaningful commit using their own GitHub account and verified commit email. Do not amend or relabel another person's commit to simulate participation.

To contribute directly, the repository owner must grant the teammate write access, then the teammate can clone or pull `main`, make a focused change, and commit from their own configured account. Before pushing, they should confirm the author shown by `git log -1 --format='%an <%ae>'`. Keep the incremental history; do not squash all team work into one final commit.
